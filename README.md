# AnimeVerse AI

A mobile-friendly anime creation studio starter website.

## Included
- Home dashboard
- Character creator and local character collection
- Demo character roleplay chat
- Story outline builder
- World profile builder
- Anime image-prompt builder
- Local saved creations

## Run locally
Open `index.html` in a modern browser.

## Important
This is a front-end starter/demo. Real AI chat and actual image generation require connecting an AI model and image-generation API through a secure backend. Do not put private API keys in browser JavaScript.

User creations are currently stored in the browser's local storage on that device.
